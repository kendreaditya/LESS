# LESS Analysis Project

## Overview

This project implements the Landing Error Scoring System (LESS) and provides tools for analyzing joint angles during the gait cycle. It is based on the data from the study by Padua et al. (2009) on the validity and reliability of the LESS. The project also includes additional functionality for pose estimation, acceleration analysis, and joint angle calculations.

## Components

### LESS Package

The `LESS` package contains the core functionality of the project:

- `__init__.py`: Implements the Landing Error Scoring System (LESS) based on the data from Padua et al. (2009).
- `angledist.py`: Provides functions for analyzing the distribution of joint angles during the gait cycle.

### Additional Scripts

- `LESS_scoreing.py`: Script for scoring the LESS based on video input.
- `ang_vel_acc_jerk_analysis.py`: Script for analyzing angular velocity, acceleration, and jerk during the gait cycle.
- `pose.py`: Script for pose estimation and analysis.

### Outputs

The `outputs` directory contains the output files generated by the analysis scripts:

- `LESS_scoring.mp4`: Video output of the LESS scoring.
- `output.mp4`: General output video.
- `output_with_acceleration.mp4`: Video output with acceleration analysis.
- `pose.mov`: Video output of pose estimation.

### Tests

The `tests` directory contains unit tests for the project:

- `LESS.py`: Unit tests for the LESS implementation.
- `angles.py`: Unit tests for the angle analysis functions.
- `__init__.py`: Initialization file for the tests package.

### Tools

The `tools` directory contains additional utility scripts:

- `__init__.py`: Initialization file for the tools package that includes calculation of joint angles and acceleration.

## Setup and Installation

1. Clone the repository:
   ```
   git clone https://github.com/kendreaditya/LESS-analysis-project.git
   cd LESS-analysis-project
   ```

2. Create and activate a virtual environment:
   ```
   python3 -m venv env
   source env/bin/activate  # On Windows use `env\Scripts\activate`
   ```

3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

To run the LESS scoring analysis:

```
python LESS_scoreing.py --input_video path/to/video.mp4
```

To run the angular velocity, acceleration, and jerk analysis:

```
python ang_vel_acc_jerk_analysis.py --input_video path/to/video.mp4
```

For pose estimation:

```
python pose.py --input_video path/to/video.mp4
```
